## Обзор литературы

### TeTIm-Eval [1]

Сравнение пяти text-to-image моделей: **DALL·E 2**, **Latent Diffusion**, **Stable Diffusion**,
**GLIDE** (диффузионные) и **Craiyon** (авторегрессионный трансформер-декодер).

| Модель | Подход |
|---|---|
| DALL·E 2 | prior генерирует CLIP-эмбеддинг изображения по подписи, диффузионный декодер восстанавливает изображение; апсемплинг 64→256→1024 |
| Latent / Stable Diffusion | VQ-VAE кодирует изображение в латентное пространство (понижение ×8), U-Net с cross-attention на эмбеддингах CLIP ViT-L/14 выполняет диффузию в латентах |
| GLIDE | диффузия в пиксельном пространстве (ADM) с текстовым обусловливанием через Transformer, апсемплинг 64→256 |
| Craiyon (DALL·E mini) | VQGAN (понижение ×16) + GPT-подобный авторегрессионный трансформер, 1024 токена изображения |

Модели сравнивались на 300 парах «изображение–текст» по CLIP score и по оценке людей
(пользователь угадывает реальное изображение; чем ниже точность человека, тем лучше модель).
FID в экспериментах не использовался: на малой выборке метрика ненадёжна.
Человеческая точность согласуется с CLIP score.

### Hierarchical Text-Conditional Image Generation with CLIP Latents (unCLIP) [2]

Генеративный стек из двух частей:

- **prior** `P(z_i | y)` — генерирует CLIP-эмбеддинг изображения по подписи
  (авторегрессионный или диффузионный вариант);
- **декодер** `P(x | z_i, y)` — диффузионная модель, «инвертирующая» CLIP-кодировщик.

Так как `z_i` — детерминированная функция `x`, `P(x|y) = P(x|z_i, y)·P(z_i|y)`.
Латентное пространство CLIP позволяет строить вариации изображения, интерполировать
между изображениями и семантически редактировать их через разность текстовых эмбеддингов.
По оценкам людей unCLIP сопоставим с GLIDE по фотореализму и превосходит по разнообразию.

### ERNIE-ViLG 2.0 [3]

Крупная китайская диффузионная модель. Улучшения:

1. знания о ключевых элементах сцены (текстовые и визуальные) при обучении;
2. **mixture-of-denoising-experts** — разные сети-эксперты на разных этапах шумоподавления.

Прямой процесс: `x_t = √α_t·x_{t−1} + √(1−α_t)·ε_t`; U-Net предсказывает шум `ε`,
текст подаётся через кросс-модальное внимание. Обучение: 320 GPU A100, 18 дней,
DDPM на 1000 шагов, инференс DDIM на 50 шагов.
Результат — zero-shot FID-30k **6.75** на MS-COCO, лучше DALL·E 2 и Stable Diffusion
по оценкам людей на ViLG-300.

## Практическая часть

Выбрана модель **Stable Diffusion** в реализации
[Stable Diffusion web UI (AUTOMATIC1111)](https://github.com/AUTOMATIC1111/stable-diffusion-webui).
Бот получает текст от пользователя, отправляет POST-запрос к модели и возвращает
сгенерированное изображение. Генерация одного изображения 512×512 за 20 шагов занимает
около 3 секунд на использованной видеокарте.

В этом репозитории исходный скрипт из приложения к курсовой переработан:
бот (aiogram 3) и сервис инференса (FastAPI) разделены, настройки вынесены в `.env`,
добавлены тесты и Docker.
